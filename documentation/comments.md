# Comments

Comments are disabled in the Stack Project of Geometric Measure Theory and Variational Problems edition. No inherited discussion threads or giscus repository/category IDs are used.

When comments are requested, configure Discussions and giscus for `aosunmath/GMT-stack`, then populate `comments.json` with this repository’s `repo_id`, `category`, `category_id`, and `category_slug`, and set `enabled` to `true`. Keep `repo` set to the fork and `term_prefix` set to `Stack Project of Geometric Measure Theory and Variational Problems`. Do not reuse Xia’s identifiers.

`giscus.json` lists the GMT Pages origin and local preview origins. Comment threads use stable page routes, independently of headings and source revisions. The reader retains its comment loading code and GitHub fallback links for when the service is configured. No credentials belong in these files.
