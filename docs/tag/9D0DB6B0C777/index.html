Definition 16.1.6 (The middle-thirds Cantor set and its probability measure)9D0DB6B0C777

Definition 16.1.6 (The middle-thirds Cantor set and its probability measure).9D0DB6B0C777 Let $C_ k$ be the union of the $2^ k$ closed intervals of length $3^{-k}$ obtained by retaining the left and right thirds at each of $k$ steps, and put $C=\bigcap _{k\geq 0}C_ k$. For $t\in [0,1)$ write its binary digits as $b_ j(t)\in \{ 0,1\} $, choosing the expansion eventually zero at dyadic rationals. Define

\[ T(t)=\sum _{j=1}^{\infty }\frac{2b_ j(t)}{3^ j}, \qquad \mu _ C=T_\# (\mathcal L^1\llcorner [0,1)). \]

The pushforward means $\mu _ C(A)=\mathcal L^1(T^{-1}(A))$ for Borel sets $A$. Each finite digit function is measurable, so the limit $T$ is measurable. This constructs the measure without presupposing a measure on an infinite product space.
