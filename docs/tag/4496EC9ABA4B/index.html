Theorem 14.19.4 (Curvature smoothing from slope alone)4496EC9ABA4B

Theorem 14.19.4 (Curvature smoothing from slope alone).4496EC9ABA4B For a smooth periodic graphical flow on $[s,T)$, let $V_ s=\max _{M_ s}\sqrt{1+|Du|^2}$. Then for $s<t<T$,

\[ \bigl (1+2(t-s)|A(x,t)|^2\bigr )v(x,t)^2\leq V_ s^2, \qquad |A(x,t)|^2\leq \frac{V_ s^2-1}{2(t-s)}. \]

The first estimate retains more information than the second. It depends on the starting slope but not its curvature. This is the compact periodic form of the base smoothing estimate in [EH89], Proposition 4.4, p. 461.

Proof

Lemma 14.19.3 and the compact drift maximum principle imply $Z(x,t)\leq \max Z(\cdot ,s)=V_ s^2$. This is the first inequality. Since $v\geq 1$, it implies $2(t-s)|A|^2\leq V_ s^2/v^2-1\leq V_ s^2-1$, proving the second. The proof is on any smooth compact slab, so the conclusion holds at every time before $T$. It is an a priori estimate for a flow already known to exist; a continuation or global-existence theorem requires its own parabolic input. $\square$
