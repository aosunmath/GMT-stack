Definition 2.1.1 (Radon measure)5B8B37A79F3A

Definition 2.1.1 (Radon measure).5B8B37A79F3A A nonnegative Borel measure $\mu $ on an open set $U\subset \mathbb {R}^ n$ is a Radon measure if it is finite on compact subsets of $U$ and, for every Borel set $A\subset U$,

\[ \mu (A)=\inf \{ \mu (O):A\subset O\subset U,\ O\text{ open}\} =\sup \{ \mu (K):K\subset A,\ K\text{ compact}\} . \]

We use its completion when integrating measurable functions. Its support consists of the points $x\in U$ for which every neighborhood has positive measure. Local finiteness does not require $\mu (U)<\infty $. See [Sim18], Chapter 1, Section 5, Definition 5.6, p. 31, for the corresponding outer-measure formulation.
