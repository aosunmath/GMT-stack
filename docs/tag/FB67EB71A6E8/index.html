Definition 8.7.1 (A pulled-tight minimizing sequence)FB67EB71A6E8

Definition 8.7.1 (A pulled-tight minimizing sequence).FB67EB71A6E8 For a fixed flat-homotopy class $\Pi $ of $\mathbf F$-continuous maps on a finite simplicial complex, a minimizing sequence is called pulled-tight if every member of its critical set is stationary. This is [MNIndex], Definition 2.9. The terminology records stationarity, not smoothness, multiplicity one or index control.
