Lemma 12.8.1 (Two first-order factorizations)AFBF4999E313

Lemma 12.8.1 (Two first-order factorizations).AFBF4999E313 Set

\[ \mathcal A=\frac d{dt}+\sqrt2\tanh (t/\sqrt2),\qquad \mathcal B=\frac d{dt}+\frac1{\sqrt2}\tanh (t/\sqrt2). \]

Their formal $L^2$ adjoints reverse the derivative sign, and on smooth functions

\[ \mathscr L=\mathcal A^*\mathcal A,\qquad \mathcal A\mathcal A^*=\mathcal B^*\mathcal B+\frac32, \qquad \mathcal B\mathcal B^*=-\frac{d^2}{dt^2}+\frac12. \]

For $f\in H^1(\mathbb R)$, $Q(f)=\| \mathcal A f\| _2^2$. Its zero space is exactly $\operatorname {span}\{ \psi \} $.

Proof

For $D=d/dt$ and a real function $b$, $(D+b)^*(D+b)=-D^2+b^2-b'$ and $(D+b)(D+b)^*=-D^2+b^2+b'$. Insert $b=\sqrt2\tanh (t/\sqrt2)$ and then $b=\tanh (t/\sqrt2)/\sqrt2$, using $\tanh ^2+\operatorname {sech}^2=1$. Integration by parts proves the quadratic identity for compactly supported smooth functions. Boundedness of the coefficients and density extend it to $H^1$.

Since $\psi '/\psi =-\sqrt2\tanh (t/\sqrt2)$, $\mathcal A\psi =0$. If $Q(f)=0$, the weak first-order equation gives $(f/\psi )'=0$ on every bounded interval, where $\psi $ is smooth and bounded away from zero. The constants agree on overlaps, so $f=c\psi $ globally. Conversely these functions lie in $H^1$ and have zero quadratic form. $\square$
