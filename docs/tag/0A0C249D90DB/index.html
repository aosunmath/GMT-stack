Lemma 5.5.2 (The calibration defect and equality condition)0A0C249D90DB

Lemma 5.5.2 (The calibration defect and equality condition).0A0C249D90DB For a compactly supported integer rectifiable current $T$ of finite mass,

\[ \mathbf M(T)-T(\omega ) =\int \bigl (1-\langle \omega ,\tau _ T\rangle \bigr )\, d\| T\| \geq 0. \]

Equality holds exactly when the local calibration condition holds almost everywhere.

Proof

Use the oriented rectifiable representation and mass formula in Definition 5.1.5. Its unit tangent vector is simple, so the comass bound gives $\langle \omega ,\tau _ T\rangle \leq 1$. The difference is the integral of a nonnegative function, and it vanishes if and only if that function vanishes almost everywhere. The sign of the orientation is part of the condition. $\square$
