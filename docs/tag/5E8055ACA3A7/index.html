Definition 5.5.1 (A current calibrated by a form)5E8055ACA3A7

Definition 5.5.1 (A current calibrated by a form).5E8055ACA3A7 A compactly supported real $m$-current $T$ of finite mass in $U$ is calibrated by $\omega $ if

\[ T(\omega )=\mathbf M(T). \]

Evaluation uses a smooth cutoff equal to one near the support of $T$. For a locally integer rectifiable current, the local calibration condition is $\langle \omega (x),\tau _ T(x)\rangle =1$ for $\| T\| $-almost every $x$. No global finite mass is required for this local condition. Compare Definition 7.2.11 and [ChMin], Theorem 16.2.
