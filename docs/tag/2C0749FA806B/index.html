Example 16.1.11 (The Cantor function has a singular distributional derivative)2C0749FA806B

Example 16.1.11 (The Cantor function has a singular distributional derivative).2C0749FA806B Let $F(x)=\mu _ C(( -\infty ,x])$. Then $F$ is continuous, nondecreasing, equals zero for $x\leq 0$ and one for $x\geq 1$, and is constant on every component of $\mathbb R\setminus C$. It satisfies

\[ F'=0\quad \mathcal L^1\text{-almost everywhere},\qquad DF=\mu _ C \]

as distributions. In particular it is locally BV but is not absolutely continuous on $[0,1]$.

Proof

A distribution function jumps precisely by its singleton mass, so Proposition 16.1.7 gives continuity. An interval disjoint from the support has zero mass, giving constancy there and zero classical derivative off the null set $C$. For $\varphi \in C_ c^\infty (\mathbb R)$, Fubini yields

\[ -\int F(x)\varphi '(x)\, dx =-\int _ C\int _ t^\infty \varphi '(x)\, dx\, d\mu _ C(t) =\int \varphi (t)\, d\mu _ C(t). \]

The finite measure derivative proves local BV. Absolute continuity on $[0,1]$ would imply $F(1)-F(0)=\int _0^1F'=0$, contradicting the endpoint values. This is an explicit singular continuous part of a BV derivative, distinct from the jump part of a step function. $\square$
