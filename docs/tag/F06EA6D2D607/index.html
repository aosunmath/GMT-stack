Remark 8.2.4 (The proof dependencies in Pitts' construction)F06EA6D2D607

Remark 8.2.4 (The proof dependencies in Pitts' construction).F06EA6D2D607 The source route is: discrete homotopies and a nontrivial class ([Pitts81], Sections 4.1–4.7), pull-tight to obtain stationarity (Section 4.3), the combinatorial argument producing almost minimizing critical limits (Sections 4.8–4.13), and replacement and regularity arguments (Chapters 5–7). Li [LiAP], Sections 3–5, separates the same topological, variational, and analytic steps. Colding–De Lellis [CDL] supplies the three-dimensional smooth-family perspective. A deformation that establishes stationarity alone does not complete the regularity step. The detailed proofs of these bridges remain to be written in this reference.
