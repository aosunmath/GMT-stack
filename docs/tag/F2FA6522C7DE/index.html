Example 2.2.4 (A plane with multiplicity)F2FA6522C7DE

Example 2.2.4 (A plane with multiplicity).F2FA6522C7DE Let $P$ be an affine $m$-plane, let $\theta >0$, and set $\mu =\theta \mathcal{H}^ m\llcorner P$. For every $x\in P$ and $r>0$,

\[ \mu (B_ r(x))=\theta \omega _ mr^ m,\qquad \Theta ^ m(\mu ,x)=\theta . \]

Indeed, a Euclidean isometry identifies $P\cap B_ r(x)$ with an $m$-dimensional ball, and the normalized Hausdorff measure agrees with Lebesgue measure on that plane. This model fixes the normalization used for tangent planes and varifolds below.
