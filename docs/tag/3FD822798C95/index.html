Lemma 3.4.5 (Directional derivatives are linear almost everywhere in each fixed direction)3FD822798C95

Lemma 3.4.5 (Directional derivatives are linear almost everywhere in each fixed direction).3FD822798C95 Suppose $f:U\to \mathbb R$ is locally Lipschitz, and put $g=(\partial _1f,\ldots ,\partial _ mf)$ where the coordinate derivatives exist, giving them arbitrary values on the null exceptional set. Then $g\in L^\infty _{\rm loc}(U;\mathbb R^ m)$. For each fixed unit vector $v$, the directional derivative $D_ vf$ exists almost everywhere and equals $v\cdot g$ almost everywhere. The exceptional set in this assertion may depend on $v$.

Proof

Existence and local bounds follow from Lemma 3.4.3. If $\phi \in C_ c^\infty (U)$, small difference quotients have a common compact support after multiplication by $\phi $ and are uniformly bounded there by local Lipschitz constants. Translation and dominated convergence give

\[ \int D_ vf\, \phi =-\int f\, D_ v\phi . \]

Use the same identity for the coordinate directions and $D_ v\phi =\sum _ iv_ i\partial _ i\phi $ to obtain $\int (D_ vf-v\cdot g)\phi =0$. Lemma 3.4.4 proves the claimed equality. Localizing the test to finitely many small neighborhoods justifies the bound when no single Lipschitz constant has been specified globally. Compare [Sim18], proof of Theorem 1.4, equations (2)–(4), p. 45. $\square$
