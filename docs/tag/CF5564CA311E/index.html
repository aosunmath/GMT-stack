Proposition 12.8.2 (The bounded kernel on the line)CF5564CA311E

Proposition 12.8.2 (The bounded kernel on the line).CF5564CA311E Every bounded $C^2$ solution of $\mathscr Lf=0$ on $\mathbb R$ is a constant multiple of $\psi $. More generally, all solutions have the form

\[ f(t)=\psi (t)\left(c_1+c_2\int _0^ t\psi (s)^{-2}ds\right). \]

The second independent solution grows exponentially as $t\to +\infty $ and is unbounded.

Proof

Write $f=\psi v$ and use $\mathscr L\psi =0$. The equation becomes $(\psi ^2v')'=0$, yielding the formula. Since $\psi (t)=2\sqrt2 e^{-\sqrt2t}(1+o(1))$ as $t\to +\infty $, its second solution is asymptotic to a nonzero constant times $e^{\sqrt2t}$. A bounded solution therefore has $c_2=0$. Conversely $\psi $ is bounded. This proves the one-dimensional assertion in [ChAC], Problem 2(b), without assuming that a bounded solution is square integrable in advance. $\square$
