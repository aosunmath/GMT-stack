Theorem 11.11.6 (Bounded Jacobi fields on a noncylindrical unduloid)88B3A10F8389

Theorem 11.11.6 (Bounded Jacobi fields on a noncylindrical unduloid).88B3A10F8389 Every smooth bounded real Jacobi field on the complete unduloid with $0<a<1/H$ is the normal component of an ambient translation. Thus the bounded kernel is exactly three-dimensional. This is the bounded part of the geometric-field description in [Maz02], p. 9; the proof below does not claim weighted Fredholm estimates or a full classification of exponentially growing fields.

Proof

Proposition 11.11.5 eliminates all frequencies $|k|\ge 2$. Fourier uniqueness leaves only the angular zero, cosine and sine sectors. In each sector the Jacobi equation is a second-order linear ODE in $t$, whose solution space has dimension two by uniqueness of the initial-value problem. Proposition 11.11.2 supplies two independent solutions in each sector. In the zero sector, the neck field has nonzero linear drift by Proposition 11.11.3, while the vertical translation field is periodic. Hence boundedness leaves only the latter. In each first angular sector the rotation coefficient $zz'+rr'$ is unbounded, while $z'$ is periodic, leaving only its translation coefficient. All three retained fields are bounded and independent, completing the proof. The cylinder endpoint is excluded: axial translation has zero normal component there and additional bounded oscillatory axial fields appear. $\square$
