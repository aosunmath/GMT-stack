Proposition 11.5.2 (The constrained Jacobi equation has a constant right-hand side)2927E9BDF88B

Proposition 11.5.2 (The constrained Jacobi equation has a constant right-hand side).2927E9BDF88B For $f\in \mathcal Z$, the constrained Jacobi condition is equivalent to

\[ Jf=b\quad \hbox{on }\Sigma \]

for some real constant $b$. Moreover $b=\operatorname {Area}(\Sigma )^{-1}\int _\Sigma qf\, dA$. This is [BdCE88], Proposition 2.9.

Proof

Integration by parts gives $Q(f,g)=-\int gJf$. If $Jf=b$, the latter expression vanishes for all $g$ of zero mean. Conversely let $b$ be the average of the smooth function $Jf$ and take $g=Jf-b\in \mathcal Z$. The nullspace condition gives $0=-\int (Jf-b)Jf=-\int (Jf-b)^2$, hence $Jf=b$ everywhere. Integrating the equation and using $\int \Delta f=0$ gives the formula for $b$. If $q$ is constant, then $b=0$ since $f$ has zero mean; for variable $q$ that deduction is unavailable. $\square$
