Theorem 9.1.5 (Weyl law for the volume spectrum)272A35DD519B

Theorem 9.1.5 (Weyl law for the volume spectrum).272A35DD519B For each $n\geq 1$ there is a constant $a(n)>0$, depending only on $n$, such that every smooth closed connected $(M^{n+1},g)$ satisfies

\[ \lim _{p\to \infty }p^{-1/(n+1)}\omega _ p(M,g) =a(n)\operatorname {Vol}(M,g)^{n/(n+1)}. \]

This is the closed-manifold case of [LMN], Theorem 1.1, p. 934. The source also treats compact manifolds with boundary using relative cycles. The proof, based on localization and comparison with Euclidean domains, is not yet included. The exponent agrees with Lemma 9.1.4; the theorem does not assert an exact formula for any fixed finite $p$.
