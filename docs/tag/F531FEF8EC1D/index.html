Proposition 7.6.3 (Positive Jacobi fields imply stability)F531FEF8EC1D

Proposition 7.6.3 (Positive Jacobi fields imply stability).F531FEF8EC1D If $w>0$ is smooth on a two-sided minimal hypersurface and $Jw=0$, then for every compactly supported smooth $\phi $ in its interior,

\[ Q(\phi ,\phi )=\int _\Sigma w^2\left|\nabla \left(\frac\phi w\right)\right|^2dA\geq 0. \]

In particular the hypersurface is stable in the sense of Definition 7.6.1.

Proof

Set $\eta =\phi /w$. Expanding $|\nabla (w\eta )|^2$ and subtracting $q w^2\eta ^2$, the terms other than $w^2|\nabla \eta |^2$ integrate to $\int \nabla w\cdot \nabla (w\eta ^2)-qw^2\eta ^2=-\int w\eta ^2(\Delta w+qw)=0$. There is no boundary term because $\eta $ has compact support. This identity makes explicit the positive-Jacobi-field argument of [ChMin], Proposition 33.4. $\square$
