Corollary 6.10.9 (The singular set below density two)5CC0A191C3F4

Corollary 6.10.9 (The singular set below density two).5CC0A191C3F4 One has

\[ \dim _{\mathcal H}\{ a\in \operatorname {sing}V:\Theta (a)<2\} \leq m-1. \]

For $m=1$ this set is at most countable.

Proof

Corollary 6.10.8 excludes the top stratum difference under the density bound. The set is therefore contained in $\mathcal S^{m-1}(V)$. Apply Theorem 6.3.10; for $m=1$ use the stronger conclusion of Corollary 6.10.6. This does not assert regularity merely from density less than two. $\square$
