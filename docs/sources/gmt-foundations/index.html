Geometric measure theory and variational problems: a first reading

Stack Project of Geometric Measure Theory and Variational Problems contributors

These contributions appear throughout the shared chapters.

Manuscript snapshot SHA-256 606cd42e8fe8b36b. This identifies the exact local source files used for this build.

Original exposition connecting classical GMT with minimal surfaces, elliptic regularity, tangent cones, Allard regularity, Almgren-Pitts min-max theory, the volume spectrum, CMC problems, and Allen-Cahn theory. Smooth mean curvature flow includes shrinking models and Gaussian area; obstacle problems remain introductory. The source inventory identifies supplied editions and checked passages. Cited theorems without local proofs are marked in the text.
