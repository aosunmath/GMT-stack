Geometric measure theory and variational problems: a first reading

Stack Project of Geometric Measure Theory and Variational Problems contributors

These contributions appear throughout the shared chapters.

Manuscript snapshot SHA-256 c3d8ee9917a42499. This identifies the exact local source files used for this build.

Original exposition connecting classical GMT with minimal surfaces, Almgren-Pitts min-max theory, the volume spectrum, CMC problems, and Allen-Cahn theory. Obstacle problems and mean curvature flow have introductory scope notes. The source inventory identifies the supplied editions; source scans are not distributed. Cited theorems without local proofs are marked in the text.
